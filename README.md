# Everyday Things, Two Lines, Longer Run

A make.fun bounty entry: a two-line explanation of rain for a 10-year-old.
Line 1 explains rain in one vivid sentence built on a single analogy — a
cloud wringing itself out like a giant sponge that drank up the sea. Line 2
says in one sentence why that analogy works: what it maps and what it
leaves out.

Run `python3 main.py` — it writes the two lines to `/output/entry.txt`
(1–400 characters, as the gate requires).

Built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).
